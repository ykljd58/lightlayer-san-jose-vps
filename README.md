## 三网实测：电信和移动能跑满，联通明显不行

2026 年 7 月有一份针对 SJC Premium 的第三方测评，路由和 iperf3 数据都比较完整。

**电信**去程 CN2、回程 CN2。广州电信机房 500Mbps 环境下，单线程 iperf3 约 147–150Mbps，RTT 约 165ms。
**移动**去回程都走 CMIN2。广州移动家宽不限速时跑到 727–734Mbps，限速 600Mbps 时直接跑满，RTT 约 172–173ms。
**联通**去程走 4837 到洛杉矶，再经 Arelion 进圣何塞；回程经 Lumen 接回 4837。广州联通机房 500Mbps 环境下只有 85–118Mbps，RTT 约 178ms，个别地区丢包偏重。

闲时和晚高峰的差别不算大，电信、移动单线程普遍在 150–200Mbps，移动部分地区能上 800Mbps 以上；联通还能有 100Mbps 出头，但延迟和稳定性都落在后面。

延迟还有一项固定损耗：机器在圣何塞，线路却要绕洛杉矶，同等价位的美西产品普遍比它低 10ms 左右。165ms 上下的电信 RTT 放在美西优化机里属于正常偏上，不是最快的那个。

IP 质量方面，测试机是原生 IP，滥用标记少，带一点家宽属性。但那份测评里 Disney+ 和 Reddit 解锁失败，要靠它看流媒体的话建议另配落地。解锁结果随 IP 段变化，别人测出来能解，不代表你分到的那台也能。
